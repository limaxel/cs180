# Overview

Prokudin-Gorskii recorded scenes through red, green, and blue filters on a
single glass plate. The scans of the plates contained exposures stacked
vertically in BGR order. My goal was to split the plate into 3, align them using
translations, and combine them into one RGB image.

# Approach

I first converted every input to floating point values in the range $[0, 1]$. For
each possible displacement, I shifted the channel with `np.roll` and measured
normalized cross-correlation (NCC) against the blue channel. I scored only the
center of each image so that the black and white plate borders did not control
the alignment.

A search from -15 to 15 pixels works for the small JPEGs. The TIFF files have
much larger offsets, so I built an image pyramid by repeatedly resizing each
channel by half. I searched at the coarsest level, doubled that displacement at
the next level, and refined it within three pixels. Python loops enumerate the
small displacement windows, while NumPy computes each NCC score over all
interior pixels at once. The same search sizes and border fraction are used for
every image.

I saved a raw-pixel NCC result for every plate as the required baseline. For the
final outputs, I ran the same pyramid using gradient-magnitude features on every
image. This uses one feature metric and one set of parameters rather than
selecting settings for individual filenames.

# Better features

Emir's blue robe has very different brightness in the blue and red exposures, so
raw-pixel NCC matchesthe red channel to the wrong content. I addressed this by
computing central-difference gradient magnitudes and running the same NCC
pyramid on those features. Edges remain in similar locations even when the
channel intensities differ. I used this same gradient feature and pyramid search
for every final output. Emir is the image where the improvement over raw-pixel
NCC is most visible.

# Bells & whistles

I also implemented automatic border cropping, gray-world white balance, and
percentile contrast stretching. The crop first removes pixels wrapped by the
alignment shifts, then scans for unusually dark, bright, or flat border rows and
columns. White balance scales the average channel colors toward gray, and
contrast stretching maps the 0.5th and 99.5th percentiles toward black and
white.

# Additional collection examples

To test the algorithm beyond the provided images, I downloaded three additional
full-res TIFF scans from the Prokudin-Gorskii collection. I processed each one
with the same raw-pixel NCC metric and multi-scale pyramid settings used for the
provided TIFF images.
