Overview

Sergei Prokudin-Gorskii recorded scenes through blue, green, and red filters on a single glass plate. The scans contain those exposures stacked vertically in BGR order. My goal was to split the plate, align green and red to blue using translations, and combine them into one RGB image.

Approach

I first converted every input to floating point values in the range [0, 1]. For each possible displacement, I shifted the channel with np.roll and measured normalized cross-correlation (NCC) against the blue channel. I scored only the center of each image so that the black and white plate borders did not control the alignment.

NCC(a, b) = dot(a - mean(a), b - mean(b)) / (||a - mean(a)|| ||b - mean(b)||)

A search from -15 to 15 pixels works for the small JPEGs. The TIFF files have much larger offsets, so I built an image pyramid by repeatedly resizing each channel by one half. I searched at the coarsest level, doubled that displacement at the next level, and refined it within three pixels. Python loops enumerate the small displacement windows, while NumPy computes each NCC score over all interior pixels at once. The same search sizes and border fraction are used for every image.

I saved a raw-pixel NCC result for every plate as the required baseline. For the final outputs, I ran the same pyramid using gradient-magnitude features on every image. This uses one feature metric and one set of parameters rather than selecting settings for individual filenames.

Raw-pixel failure: Emir

Better features

Emir's blue robe has very different brightness in the blue and red exposures, so raw-pixel NCC matches the red channel to the wrong content. I addressed this by computing central-difference gradient magnitudes and running the same NCC pyramid on those features. Edges remain in similar locations even when the channel intensities differ. I used this same gradient feature and pyramid search for every final output; Emir is simply the image where the improvement over raw-pixel NCC is most visible.

Bells & whistles

I also implemented automatic border cropping, gray-world white balance, and percentile contrast stretching. The crop first removes pixels wrapped by the alignment shifts, then scans for unusually dark, bright, or flat border rows and columns. White balance scales the average channel colors toward gray, and contrast stretching maps the 0.5th and 99.5th percentiles toward black and white.

Additional collection examples

To test the algorithm beyond the provided images, I downloaded three additional full-resolution TIFF scans from the Prokudin-Gorskii collection. I processed each one with the same raw-pixel NCC metric and multi-scale pyramid settings used for the provided TIFF images.

Armianka

Green: (23, 48) · Red: (39, 110)

The face, clothing, and surrounding tree branches align clearly without noticeable double edges. Small color differences around the hands and embroidery may come from movement between exposures.

Bashkirka

Green: (20, 69) · Red: (37, 145)

The architectural lines, striped clothing, and facial features are sharply registered. This example also shows that the pyramid can recover a fairly large vertical displacement.

Chinovnik

Green: (-5, 60) · Red: (-21, 130)

The wooden walls, staircase, clothing, and facial details line up well. A few colored regions remain around hanging objects, but the main structural edges do not show alignment ghosting.
